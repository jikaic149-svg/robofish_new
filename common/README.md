# SPI 帧协议 RFS1

128字节固定帧，Mode0/MSB-first。所有多字节字段为小端，CRC32/IEEE覆盖0..123字节，结果放124..127。包类型请求1、响应2；请求长度24，响应长度56。

| 偏移 | 内容 |
|---|---|
| 0..3 | RFS1魔数/版本 |
| 4 | 帧类型 |
| 5 | bit0=STM32已就绪；bit1=允许2.4G备用控制（当前不置位） |
| 6..7 | 负载长度 |
| 8..11 | S3启动会话 |
| 12..15 | 本端序号 |
| 16..19 | 对端确认号 |
| 20..23 | 时间戳μs；STM32由毫秒Tick换算 |

请求24..27为命令ID；28类型；29动作；30模式；31功率；32转向强度；33兼容遥控命令码；34有旋钮；35刹车；36..37旋钮；38..39俯仰；40..41连续转向。类型1运动、2兼容遥控、3俯仰、5连续目标；**类型4已移除并拒绝**。

响应24..27命令ACK；28结果1接受/2拒绝；29模式；30动作；31功率；32转向强度；33failsafe；34控制来源；**35电池状态（0正常、1低压、2高压、3采样无效/过期）**；36..39输出尝试；40..43输出失败；44..47SPI接收；48..51非法帧；52..55队列溢出；56..59传输错误；60链路在线；**61电池采样有效；62..63采样年龄ms（uint16，最大65535）**；64/66/68/70为四舵机角度×100的int16；72/74为两路ESC百分比int16；76俯仰int16；**78..79电池电压mV（uint16）**。

其它字节保留为0。电池数据占用原保留字段，帧长度不变。响应通常反映前一轮请求；递增ACK验证心跳，缓存旧帧不维持在线。100ms离线仅报告状态，保留LoRa，不停运动。

LoRa主控、2.4G仅备用。用户已确定失联后新指令接管、LoRa恢复优先，但心跳周期与丢失超时未定；当前不授予备用控制，STM32拒绝SPI运动，S3不入队。Demo已移除。电压前馈现按2S/7.4V基准启用，使用每周期当前两路油门分别补偿，72/74两路ESC百分比为补偿后驱动接受的控制值。运行范围6.6～8.4V（含边界）；超出范围或采样无效/过期保持运动停止，恢复后需新有效指令。61仍表示ADC换算有效且未过期，不表示电压适合运行；保护以滤波前原始电压判断。
SPI 每次CS低电平只传128字节，S3在传输完成后保证至少100μs的CS高电平间隔。STM32在NSS释放且RX/TX两路DMA均收尾后才复制发送快照、准备下一帧；短/长帧和部分启动失败清理后恢复。目标1ms周期，实际周期可能因调度和间隔约束延长，尚未上板测量。LoRa文本协议见 [LORA_PROTOCOL.md](LORA_PROTOCOL.md)。
