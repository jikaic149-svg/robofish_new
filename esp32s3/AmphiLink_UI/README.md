# 机器鱼工作站

双击桌面“机器鱼工作站”，自动启动后台服务并打开 http://127.0.0.1:8765/ 。无需手动运行Python。所有网页运行在电脑，S3只提供管理API和相机。

## 常用操作

| 页面 | 用途 |
|---|---|
| 操控 | 同屏查看实时画面、电池、控制权、安全状态、六路输出和三轴控制 |
| 视觉 | 原VISION程序的原始视频、识别/跟踪画面、标定、路径、循迹和录像；可单独打开窗口 |
| 数据 | 后台记录、按单位绘制曲线、冻结查看、CSV/JSON与PNG导出 |
| 开发 | 同一处选择USB/Wi-Fi、连接、暂停/继续、源码单步、烧录、变量波形、外设、RTOS、内存占用、ESP32升级 |

设备设置放在左下角，日志统一为底部抽屉。开发页的探针、目标芯片和链路状态常显；底层直连、内存与手动镜像操作保留在高级维护中。

操控页按住W/S前后、A/D转向、R/F浮沉，可同时按；例如W+A+R为左前并上浮。松开某一轴仅释放该轴；失焦、切页和空格释放全部输入。鼠标八方向与浮沉支持多个指针组合。

**运动模式选择会立刻执行独立配置任务，返回应用结果，不需要再点方向，也不启动或续期运动。** 指令来源独立选择通道，控制权仍由有效目标与LoRa > 2.4G > 视觉仲裁决定。目标采用会话与递增序号，停止后的旧请求会被拒绝。持续按住才按150ms续期，松开归零。

## 实物与离线测试

- LoRa任务：PC发送端与遥测上行尚未接入，实物运动不可用。明确显示待接入；没有有效数据时显示未知。
- 台架检查：通过S3 HTTP/SPI读取电池及输出，只读；实物控制权与安全原因尚未上报。
- 离线测试：使用PC模型，无需额外脚本和密码；六路目标复用STM32同一L0适配、L2根分配器和L3纯电气映射，包含模式、组合目标和执行器极性。DLL是无状态的目标预览；逐周期限速和部分写入在固件任务回归中验收。这不是鱼体物理仿真或位置反馈。

模型保留3秒目标有效期、链路降级、SPI启动限制、电池停机、恢复需新指令；全停后不会因断链重新上浮。视觉需要显式准备会话；人工全停、人工接管、失联或电池闭锁均让旧视觉会话失效，必须重新启动循迹。

HTTP/SPI管理链不代发运动。开发页面始终是实物工具，即使操控使用离线模型；烧录、调试必须由用户明确点击，不生成仿真假回执。模型测试不依赖探针。

## 原VISION融合

工程VISION目录来自原codeFish/VISION的程序、算法、标定配置及已有.pt权重，来源和哈希见VISION/origin.json；原目录没有修改。浏览器转接原程序的画面和任务队列，保留白头/橙尾姿态、YOLO、路径引导、初始航向/场地/颜色标定、录像和截图。

origin.json保留导入时基线；本工程副本的vision_toolbar.py已进行按钮尺寸和字体适配，识别与控制算法未改。

视觉子进程只监听随机本机端口并校验私有令牌。旧设备HTTP/UDP发送线程及平板TCP监听由运行适配层替换，所有视觉控制目标先经过工作站仲裁。原始相机与识别结果来自真实帧，网页没有合成的检测框或轨迹。

视觉页支持“板载视觉单窗口、视觉控制单窗口、双窗口”，默认视觉控制单窗口并记住选择。板载画面直接使用ESP32-S3相机流，可独立于视觉推理打开；视觉控制使用原VISION程序。原画面工具栏按钮增至49px，网页操作按钮为48px；点击与标定坐标映射已核对。

“视觉参数与标定”直接定位相机、模型与标定配置：可选择摄像头索引、原录像回放及VISION/models目录内已有.pt模型；运行时先停止，再修改并启动。鱼头、鱼尾、场地和转弯标定显示已有配置，并通过原程序执行标定。采集分辨率改变需重新核对标定。

相机默认索引0。“原项目录像”只作回放，不代表运动效果。已有视觉环境为D:/python/venvs/yolo/ultralytics/8.4.118/Scripts/python.exe，其他机器可设置ROBOFISH_VISION_PYTHON。录像、截图与原视觉CSV进入build/vision，点击“录像与截图文件”打开目录。

## STM32调试与烧录

复用BakeSheep.emberprobe 0.8.3及其原生GDB/DAP、变量波形、SVD、RTOS与ELF分析。桥接扩展0.2.0把原版控件和消息处理接入网页；源码行断点、条件/函数断点、线程、调用栈、作用域树、内存读写与GDB控制台集中在开发页。常规功能逐项对照见[核对表](../../docs/EMBERPROBE_PARITY.md)。

首次点击“仅启动工具”或“连接调试”会打开本项目的独立VS Code宿主；工作区须可信，宿主需保持运行。新电脑先安装EmberProbe，再运行tools/emberprobe/install.cmd。已有SDK时可使用install.py --bridge-only。原版文件选择、SVD许可、驱动和写入授权对话框仍保留。扩展更新后需重载宿主。

顶部“调试符号ELF”默认选择stm32f405/build/debug/RoboFishF405.elf。连接采用attach，会暂停内核，不自动下载或复位。烧录默认选择匹配的RoboFishFactory.elf，含Bootloader、启动记录和A/B，限USB有线。烧录先展示文件与哈希计划，确认后交给原生授权；拒绝直接返回。先全停并断开调试，NRST须连接。

OpenOCD固定D:/OPENOCD/openocd-custom-20260922，GDB使用D:/GCC/ARMGCC/10 2021.10/bin/arm-none-eabi-gdb.exe。工具路径为公开工作区配置。目标脚本避免厂商reset-init强制8MHz，复位擦写时核对看门狗冻结位；硬件时序和实际烧录仍须上板验收。

调试、升级与配网写入互斥，后台遥测/记录/视频不占用全局调试锁。暂停前全停机器鱼。实物未接入，本轮没有执行下载、擦除、复位或调试设备。

## 数据、鉴权与边界

记录保留最近30,000个样本，满后显示丢弃计数；来源改变前须停止、导出和清空。记录保存在服务内存，退出前导出。无效样本留空，曲线按V、%、°、ms分组。浏览器日志保留2000条，可筛选搜索与导出。

顶部“记录仿真数据 / 记录台架遥测”每秒保存一条：时间、来源、有效标记、电压、油门、六路执行器、延迟、控制权、安全状态及原因。它不包含视频，视频通过视觉页“录制视频”保存。页面常显当前记录来源、数量和内容说明；LoRa上行未接入时实物任务记录禁用。

设备密码不预填、不进入URL/浏览器存储/日志；可选Windows当前用户DPAPI加密保存。保存密钥至少12位且非纯数字。当前设备为共享密钥，没有多人角色权限；未自动轮换旧设备密码。相机依用户要求保持免鉴权。

所有本地POST校验Host、Origin与随机令牌。任务桥令牌保存在宿主私有存储，不随交付包或日志导出。完整受限无线升级与S3延后健康确认仍待实施，维护入口不代表防变砖OTA已验收。此次没有修改STM32或S3固件。
