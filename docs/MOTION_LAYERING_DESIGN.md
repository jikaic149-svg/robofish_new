# 运动机构、运动能力与控制分层设计

状态：2026-10-15 已实现 L0–L3 开环控制链和传感器接入契约，软件验收见[运动控制验收](../.agent_reports/motion_control_acceptance_2026-10-15.md)。本文的物理能力与候选高级方案仍为设计／研究内容；未完成实机标定。

本文回答三个问题：各机构通过什么机理作用于鱼体；这些作用能组成哪些整机运动；软件应如何表达、分配和执行运动请求。胸鳍与浮沉的文献依据、计算假设和验证方法另见[研究报告](../pectoral_fin_depth_control_report.md)。安全行为以[安全与升级设计](SAFETY_AND_UPDATE_DESIGN.md)为准。

按层实施的阶段、产物与验收条件见[运动控制分层实施计划](MOTION_CONTROL_IMPLEMENTATION_PLAN.md)。该计划先建立基线和接口，再从 L3 向 L0 逐层推进。

## 1. 分类规则

原先的“运动形态 / 运动性质”不能承担全部分类：其中混入了机构结构、运动方法、整机效果、软件约束和传感器。本文改用下面五类，按所回答的问题归类。

| 类别 | 回答什么 | 本项目中的例子 |
|---|---|---|
| 机构构成 | 有什么器件、怎样安装、能绕哪些轴运动？ | 两个串联尾关节、左右胸鳍、侧置双桨 |
| 物理作用与响应特性 | 给定运动和工况，会产生什么力 / 力矩，怎样变化？ | 胸鳍载荷依赖局部来流；双桨差推力产生偏航力矩 |
| 整机运动能力 | 鱼体最终能做什么，需要什么条件？ | 前进、后退、转向、改变俯仰、上浮、下潜 |
| 执行器运动方案 | 为实现目标，让哪些执行器怎样随时间运动？ | 连续摆尾、带偏置摆尾、半周期快慢不同、胸鳍保持偏角 |
| 控制与软件实现 | 怎样把请求转成可执行输出，并处理约束和提交结果？ | 来源仲裁、步态调度、相位积分、成对缩放、PWM 映射 |

这五类是描述视角，不是五级软件架构。一个完整方案可以依次说明这五件事，但不能把它们排成同一张“运动类型”表。

具体归类如下：

| 原条目 | 正确归属 | 原因 |
|---|---|---|
| 振幅、频率、相位差、占空比 | 运动方案的参数 | 描述输入轨迹，不直接说明力的大小 |
| 舵机带宽、机械行程、流体分离 | 物理约束 / 工况边界 | 限制可执行或有效的输入范围 |
| 关节权重、摆幅收缩、成对缩放 | 分配与约束处理 | 是求解方法，不是新的运动能力 |
| 桶式转向 | 双桨差动的一种运动方案 | 一正一反是输入组合，能否近似原地转取决于真实推力 |
| “胸鳍导向、尾 / 桨供能” | 整机协同方案 | 不是胸鳍唯一或固有的物理作用 |
| 正浮力、被动复原 | 整机物理性质 | 不是执行器，也不是控制算法 |
| 相机、压力、IMU、电流 | 观测与验证条件 | 决定哪些状态可观测，不属于运动方案 |

本文用“源码现状”“设计方案”“待验证”区分证据状态。文献平台的结果不标成“本机已验证”。

## 2. 机构构成与术语

### 2.1 本轮采用的构型

| 对象 | 构成与运动自由度 | 确认边界 |
|---|---|---|
| 尾部 | 两个串联关节，在水平面内摆动 | 沿用本轮机构讨论；关节轴、长度和柔性段仍需实物记录 |
| 双桨 | 鱼体左右各一只，按纵向双向推进建模 | 轴线方向、中心距、推力线高度、旋向和正反推力曲线待测 |
| 胸鳍 | 左右各一个转动执行器，镜像布置 | 需记录实际转轴、鳍面零位、舵盘传动关系和面积 |
| 鱼体 | 按略正浮力、具有被动复原能力的目标设计讨论 | 实际净浮力、重心、浮心和复原力矩尚无本轮测量 |

软件中的六路输出可以确认；输出名称不能代替安装几何的测量。尤其不能由“两桨侧置”直接断言胸鳍或尾舵一定处于滑流内、外。

### 2.2 四种角度必须分开

- **机体姿态角**：鱼体相对水平面的俯仰、横滚、偏航。
- **关节角**：相邻尾段之间的相对转角。
- **鳍面有效迎角**：鳍面弦线与局部相对来流之间的角度。
- **舵机命令角**：标定后送给驱动的数值，包含中立偏置和安装方向。

文献中的尾鳍 pitch 通常指鳍面相对来流的转动，不自动等于鱼体抬头 / 低头。舵机离中位 25°，也不自动等于有效迎角 25°。

上层指令继续沿用“前进为正、右转为正、抬头意图为正”的人机语义。当前 `AttitudeSample` 使用 FLU（前 / 左 / 上），其 yaw 正方向为左转；接反馈时必须显式完成坐标和符号转换。本文不修改现有接口。

## 3. 物理作用与响应特性

本节描述作用机理，不规定控制器怎样实现这些作用。

### 3.1 尾部

尾部运动通过改变周围水的动量，对鱼体产生时变力和力矩。在本轮水平面构型中，主要研究纵向推力、侧向力和偏航力矩；不把它视为独立的俯仰或横滚执行器。

响应取决于两个关节的运动、尾鳍几何与柔性、鱼体速度及载荷。`频率 × 关节角幅值`只描述关节运动速度，不能直接当成推力或航速。

对称周期输入在理想左右对称条件下，可能抵消周期平均侧向作用；偏置、时间不对称和幅值不对称会打破这种对称性。偏航方向和强度需要测量，不能只凭舵机数值符号确定。

必须区分：持续摆动可以自行产生相对流动；保持静态偏角需要外部来流或滑流才有持续舵效。因此，零航速不等于所有尾部转向方法均失效。

尾部反向推力保留为待验证能力。把两个正弦同时乘 −1 只是整体平移半个周期，不等于反向行波；改变关节相位关系也不保证这套实物必然产生后退推力。

**分段推力分布的已有数值结论（[16]，1.493 m、48.567 kg 的三关节尾部 CFD 模型）**：纯尾推进下，**头部与第二尾关节主要产生阻力；第一尾关节与尾鳍产生推力，其中尾鳍是主要推力来源**。混合推进时提高尾频与桨速会使**头部阻力显著上升、第二关节阻力略升、第一关节推力略增，而尾鳍推力略降**。

该结论对本机有两处直接含义，但均为待复核假设：

1. **某个尾段平均受阻不等于驱动该关节无益**。关节运动会改变后续尾段和流场，不能由单段纵向力符号推导本机后 / 前角幅值比；应比较完整输入下的总作用、轨迹与功耗。
2. **加入桨推力可能改变甚至削弱尾鳍的推进贡献**；各机构单独运行的推力不能不加条件地相加。[26] 对背鳍 / 臀鳍 + 单桨的功率近似叠加结果，既非同一构型，也不证明推力线性叠加。

同一文献的理想对称模型中，侧向力 / 系数的周期均值约为零，幅值随工况变化。这支持对称性分析，不保证实物在安装偏差、水流或初态扰动下仍严格为零。

### 3.2 双桨

令左右桨的**真实纵向推力**为 `T_L`、`T_R`，单位 N；左右推力线距中线的距离均为 `d`。理想平行安装下：

```text
纵向合力       = T_L + T_R
偏航力矩的大小 = d · |T_L − T_R|
```

总桨间距是 `2d`，不能再把总间距乘一次推力差。力矩正负由统一坐标及实物方向确定。

若推力线与重心存在高度差，还可能产生俯仰力矩；桨的反扭矩失衡可能产生横滚扰动。两桨对转只能在相应转速 / 负载匹配时抵消反扭矩，不代表任意差动下都抵消。

命令百分比不是牛顿。两路等值反号命令能否形成近似纯力偶，取决于各自的正反推力曲线和安装状态。其他型号的“反推约为正推的 78%”不能用作本机常数。

滑流可能改变下游鳍面的局部流速和方向。是否覆盖鳍面、覆盖多少、反转后怎样变化，属于几何与工况问题。

### 3.3 胸鳍

胸鳍承受的流体载荷作用于鱼体，并形成合力和力矩。静态水翼近似下，载荷与局部来流速度的平方有关；局部来流可以来自航行、桨流或环境水流。

在左右对称、鳍力主要为竖向的简化条件下：

- 两鳍竖向力的共同分量主要改变竖向合力及俯仰力矩。
- 两鳍竖向力的差动分量主要产生横滚力矩。
- 横滚诱导转向属于整机耦合响应，不能当成胸鳍独立、直接的偏航输入。

静态无来流时，水翼近似不能提供持续控制力。主动扑动属于另一种非定常运动方案，可能自行造流，需根据实际转轴与行程单独建模和验证。

胸鳍同时具有直接竖向力和姿态力矩。“通过调整俯仰来引导尾 / 桨推力”是本机可研究的一种协同用法，不应据此删除胸鳍自身的竖向力。

### 3.4 鱼体与浮力

净浮力是浮力与重量的差，决定停推进后的竖向趋势；它不是整机重量。重心、浮心及其相对位置决定静态复原特性，水动力阻尼影响姿态变化过程。

略正浮力可以提供停推进后的上浮趋势，但不能单凭“正浮力”给出上浮速度、时间或所有姿态下的恢复保证。

## 4. 整机运动能力

能力是鱼体的结果，不按软件模式名定义。下表是设计判断，尚不构成本机水池性能验收。

| 能力 | 可研究的作用来源 | 成立条件与边界 |
|---|---|---|
| 前进 | 尾部平均推力、双桨共同推力 | 推力克服阻力；实际速度待标定 |
| 后退 / 主动减速 | 双桨反推；尾部反向方案待验证 | 分开标定减速效果与稳定后退能力 |
| 改变航向 | 桨差推力、尾部非对称运动、来流中的尾舵 | 转向同时可能有平移；低速、巡航需分别测 |
| 改变俯仰 | 胸鳍力矩、偏置推力线等 | 力矩需克服复原与水动力作用；不能直接承诺角度 |
| 改变横滚 | 胸鳍差动载荷等 | 无姿态观测时只能给开环输入，不能声称闭环稳定 |
| 上浮 | 正净浮力、推进 / 鳍力的向上分量 | 停推进上浮与主动上浮分开描述 |
| 下潜 | 推力随机体倾斜产生的向下分量，加上鳍面竖向力 | 同时满足姿态与竖向力预算，见研究报告 |
| 定深 / 悬停 | 持续竖向平衡与必要的状态反馈 | 水平定深巡航、零水平速度定深、完全停机定深是三种不同要求 |

当前没有接入可用的深度 / 姿态闭环，不把定时动作称为定深控制。视觉能提供哪些观测量取决于相机位置、标定和特征可见性；已有相机不自动提供深度或六自由度姿态。

## 5. 执行器运动方案

本节只规定输入轨迹。括号中的编号保留原讨论索引，便于继续讨论，不代表独立的软件模块或已验证能力。

### 5.1 尾部方案

| 方案 | 输入怎样变化 | 当前状态 |
|---|---|---|
| 连续周期摆动（T1） | 两关节持续正弦运动 | 已有生成代码；实机推力 / 速度未在本轮验证 |
| 关节幅值分配（T2） | 分别选择两个关节的幅值 | 当前后 / 前关节角幅值比为 0.9；这不等于尾尖位移包络 |
| 关节相位配置（T3） | 设置第二关节相对第一关节的相位差 | 当前为 60° / 72°；最优值未知 |
| 带偏置摆动（T4） | 在周期轨迹上叠加平均角偏置 | 已有代码 |
| 周期内时间不对称（T5） | 左右半划用不同时间 / 速度曲线 | 待设计与标定；峰值速度仍须受限 |
| 间歇摆动（T6） | 交替安排摆动段与滑行段 | 待验证；不能绕过摆动段的瞬时带宽约束 |
| 局部关节运动（T7） | 指定一个关节保持、另一个关节运动 | 待验证；不预设远端关节在所有工况都更优 |
| 左右幅值不对称 | 左右半划幅值不同 | 待验证，可与偏置 / 时间不对称组合 |
| 反向 / 制动候选 | 改变相位关系等输入参数 | 未验证，不与当前“反向标志”混同 |
| 静态尾舵 | 保持尾部偏角，不周期摆动 | Prop 转向已有此代码；舵效依赖局部来流 |

T8“摆幅饱和收缩”移至第 8 节，它是约束处理，不是另一种尾部运动。

T1 的四个问题可明确为：**谁在动**——两个串联关节；**怎样动**——相位错开的周期轨迹；**产生什么**——待测的周期平均纵向作用和伴随侧向作用；**怎样验收**——同时记录实际轨迹、推力或自由航速及耗电。其余方案按同一顺序展开。

### 5.2 双桨方案

| 方案 | 输入怎样组合 | 当前状态 |
|---|---|---|
| 共同推进（P1） | 两桨产生同向纵向推力 | 已有双路命令分配；左右等命令不保证等推力 |
| 差动推进（P2） | 共同分量上叠加左右差动 | 已有；当前优先保留共同命令 |
| 一正一反（P3） | 差动跨越中立，是 P2 的一种工况 | 不单列为新的自由度；近似原地转能力待测 |
| 共同反推（P4） | 两桨同时请求反向推力 | 用于减速或后退，分别标定 |

反向过中和加减速曲线归控制实现；推力不对称归响应特性。桨流与鳍面的协同在明确几何后再制定。

### 5.3 胸鳍方案

| 方案 | 输入怎样组合 | 当前状态 |
|---|---|---|
| 对称偏转（F1） | 两鳍在物理上同向改变偏角 | 已有俯仰 / 升降意图到舵机输出的映射 |
| 差动偏转（F2） | 两鳍在物理上一上一下 | 可作为横滚方案；统一四轴 roll 尚未实现 |
| 共同与差动叠加 | 同时指定两种分量 | 需联合处理共享行程 |
| 主动扑动（F6） | 给鳍角添加周期轨迹 | 候选；实际转轴、力方向及收益待验证 |

F3“导向角色”归第 4 节的整机协同解释；F4“成对缩放”归约束处理；F5“失速边界”归响应特性；F7“来流来源”归工况。镜像舵机的命令正负只在标定映射中处理。

## 6. 整机协同方案

本节区分物理关系、其他原型的结果和本机待验证方案。先确定工况、可用作用与约束，再比较分配；文献中的最高测试值、阈值或输入顺序不直接变成本机控制规则。

### 6.1 三种协同形式

| 形式 | 含义 | 本项目中的研究任务 |
|---|---|---|
| 分工 | 多个机构共同满足运动需求，在可用权限与约束下分配 | 比较尾部、双桨及混合推进在同一目标速度下的功耗 |
| 并行作用 | 多个机构同时工作，真实合力与合力矩共同决定运动 | 转向时联合考虑桨差推力、尾部作用与鳍 / 鱼体侧向载荷 |
| 时序配合 | 根据来流和执行器响应决定输入如何共同建立与撤除 | 比较同步启动、先造流后调姿态等方案 |

实际力与力矩必须合成，但各机构**单独运行时**测得的结果不能直接线性相加，因为共同工作会改变来流和载荷。“按效率分配”也不能替代满足推力、转向、行程和带宽约束。

### 6.2 前进：指标、证据与分配假设

#### 6.2.1 无量纲数描述工况，不单独决定分配

| 对象 | 描述量 | 使用条件与限制 |
|---|---|---|
| 尾部 | `St = f·A_pp/U` | `A_pp` 为实际尾尖峰峰位移；`U` 为指定参考下的相对水速度。U 为零时不能用该比值判断启动能力 |
| 螺旋桨 | `J = U_a/(nD)` | `U_a` 为桨处的轴向进流速度，可能不同于整机速度；n 的单位为转 / 秒，rpm 数据须先除以 60 |
| 桨开水效率 | `η₀(J) = J·K_T(J)/(2π·K_Q(J))` | K_T、K_Q 随工况和桨型变化，效率应查相应曲线，不能推出 J 越大越好 |
| 本机巡航能耗 | 给定速度与载荷下的电池输入功率，或统一口径的运输成本 | 需包含明确的电源 / 执行器统计边界，并同时记录轨迹和姿态 |

桨推力可写为 `T = ρ_w·n²·D⁴·K_T(J)`，其中 ρ_w 为水密度。改变转速也会改变 J，不能在任意工况下把 K_T 当常数。[47]

`J = 0` 时，按“平移有效功率 / 轴功率”定义的开水效率为零，这不表示桨不能产生静推力。起步、抗流和定点任务需另看推力、功耗及响应；巡航节能则应在相同目标速度下比较。[47]

部分摆翼研究报告 0.25～0.35 的高效 St 区间，但最佳值与模型条件有关。[3] 的分析不能化为所有机器鱼的统一窗口。[4] 中约 0.48 是其特定系留机器人整机平均推力与阻力相抵的工况，不是所有尾鳍的失速或推力反向阈值。它与 [16] 的局部鳍面系数阈值也不是同一个判据。

#### 6.2.2 两篇混合推进论文：分别记录构型、指标与结果

**论文 A：[16]，三关节尾部 + 双水平桨，CFD 与部分速度验证。**

原型长 1.493 m、质量 48.567 kg，具有三关节尾部；实物另有垂向推进器，但论文分析的是简化后的平面直线游动，未研究本机的俯仰、横滚或升沉协同。它与本机两关节尾部的尺度和几何不同。

| 内容 | 原论文给出的范围 / 结果 | 适用边界 |
|---|---|---|
| 参数扫描 | 单模式覆盖尾频 0.5～3.0 Hz、桨速 500～3000 rpm；混合模式为尾频 1.0～2.5 Hz 与桨速 750～2500 rpm 的 24 组组合 | 原型尾部速度验证最高到 1.5 Hz，较高频率的结果主要来自 CFD |
| 巡航速度与波动 | 在所测混合配置中，2.5 Hz + 2500 rpm 得到最高速度与较好的相对速度稳定性 | 是扫描范围内的结果，不是本机最优值；绝对波动幅度与相对波动指标分开解释 |
| 能量利用因子 | 所测混合配置中，2.5 Hz + 750 rpm 的该指标最高；增加尾部推力占比与该指标升高相关 | 采用其自定义指标，不直接等同电池节能 |
| 分段水动力 | 头部与第二尾段主要受阻，第一尾段与尾鳍贡献推进；混合运行改变各段作用 | 不能据某段受阻就决定本机关节幅值或删除该关节 |
| 低 St 工况 | 特定参数下 St 小于约 0.3 时，尾鳍平均纵向系数转负，部分混合配置比同转速纯桨游得慢 | 提示应比较主动摆尾与静态尾部，不构成本机自动停摆阈值 |
| 对称输入 | 理想对称运动的侧向力周期均值约为零 | 支持其模型的对称性结果，不保证有安装误差或扰动的本机严格为零 |

论文的“能量利用因子”以整机前进动能为分子，以纵横动能、关节 / 转子动能及流场能量等构成分母。它不是从电池功率积分得到的能耗，未覆盖本机电机、驱动与传动损耗；不能直接拿来制定电池节能权重。见原文 §3.2、§4.4、§5、§6。

**论文 B：[26]，背鳍 + 臀鳍 + 尾部单桨，水池实验。**

该平台模仿尖尾翻车鱼，长 336 mm、质量 3.35 kg；推进鳍是背鳍和臀鳍，属于 MPF 构型，并非本机的串联两关节尾部。两鳍使用可反馈的总线执行器，尾部为一只轴向桨，供电为 25.2 V。试验水箱为 4.5 × 1.5 × 0.8 m，水深 0.5 m。

| 内容 | 原论文报告的结果 | 必须保留的工况 |
|---|---|---|
| 仅鳍最大速度 | 0.373 m/s，约 1.11 BL/s | 扫描 1～5 Hz、±10～50°；最大值出现在 5 Hz / ±40° |
| 仅鳍运输成本 | 最低 CoT 为 0.968 | 出现在 3 Hz / ±20°，不是最大速度配置 |
| 混合最大速度 | 0.434 m/s，较仅鳍最大值增加 16.35% | 鳍固定 5 Hz / ±40°，桨占空比最高测试到 80% |
| 混合功率与 CoT | 所测配置中功率近似相加，CoT 随桨占空比增加而下降 | 功率 / CoT 图采用 ±30°，不能与 ±40° 最大速度配置混成同一个工况 |
| 转向 | 改变鳍偏置明显改变半径，加桨主要提高速度与转向角速率；最高报告 0.515 rad/s | 混合转向基线为 3 Hz / 20°，鳍偏置与桨占空比分别扫描；只是该平台的近似经验关系 |

CoT 按原文定义为 `P/(mgv)`，使用其实验功耗口径；不能直接与论文 A 的动能比例相比较。论文 B 对大幅值下的失速只是可能解释，未提供足以移植成本机鳍面限位的流场验证。见其 §II～IV。

两篇论文的构型、指标和测试范围不同。它们支持研究混合推进及其耦合，**不能证明本机必然存在“低速尾为主、高速桨为主”的交叉点**。该分工可作为候选；应比较同一台机器、同一载荷与目标速度下的纯尾、纯桨和混合输入，允许出现没有交点或混合最优的结果。

#### 6.2.3 时间不对称与 St

保持总周期 T、尾尖峰峰位移 A_pp 和速度 U 不变，只改变快划 / 慢回的时间比例，`f = 1/T` 不变，St 也不变。例如左右半划从 50% / 50% 改成 30% / 70%，不自动改变 St。

时间不对称会改变关节峰值速度、加速度和载荷时序，也可能改变自由游动的平均速度。因此应重新测量实际轨迹与 U，再计算 St，不能预设 St 一定降低。局部半划速度是另一类描述量，不能直接代替整周期频率。

### 6.3 转向：作用分配与响应

#### 6.3.1 动力学合成与运动学参数化分别使用

实际横向合力和偏航力矩由同时运行时的各部分作用合成：

```text
Y_total = Y_prop + Y_tail + Y_fins + Y_hull
N_total = N_prop + N_tail + N_fins + N_hull
```

每一项都可能随其他机构输入及流场变化；上式不表示把各机构单独试验的结果当作独立线性增益相加。机体惯性、附加质量、阻尼及耦合响应共同决定实际运动。[48]

平面轨迹的运动学关系可写为 `ω_χ = U/R_c`，其中 R_c 是轨迹曲率半径，ω_χ 是轨迹切线方向变化率。只有侧滑较小或基本恒定时，才可进一步把它近似为航向变化率。它描述运动结果，不能取代力 / 力矩模型。

论文 B 在所测工况下观察到“鳍偏置主要影响半径、单桨主要影响速度”的近似解耦。单桨也会通过改变来流影响鳍力与半径；该经验不能推广成所有构型的严格解耦。其背 / 臀鳍输入也不能直接替换成本机尾关节偏置。

本机双桨差动直接提供偏航力矩，既可能改变转弯半径，也可能改变速度；接近零平移速度时仍可研究偏航。原地转向不能通过 `U/R_c` 求控制量，需保留对航向变化的独立描述。不能把几种机构简单计数为四个独立“半径输入”。

#### 6.3.2 输入建立与撤除的候选方案

| 候选 | 需要比较什么 | 当前边界 |
|---|---|---|
| 桨差动与带偏置尾摆共同建立 | 偏航响应、侧移、推进损失及峰值载荷 | 现有偏置方案可作为基线，不能因研究时间不对称就预先删除 |
| 桨差动与尾部时间不对称共同 / 分时建立 | 延迟、平均偏航与周期波动 | 较慢响应不自动意味着必须晚启动；先后顺序需要试验 |
| 在可用来流下加入胸鳍差动 | 横滚、侧滑与偏航的耦合收益及代价 | 没有实测前，不指定其只用于维持转弯或一定更慢 |
| 保持、改变或撤除尾部偏置 | 转向效果与退出过程 | 回中可能改变控制力矩，但不等于收起鳍面或撤除航向稳定性 |

[5] 讨论控制面及可伸缩鳍对稳定性 / 机动性的影响，不支持“本机尾舵回中就失去稳定面”的推论。本文不规定固定的四阶段启动或逆序退出；只在本机取得作用方向、延迟和限幅证据后选择时序。

#### 6.3.3 差动的零净纵向力配比

令 `F_L,fwd(a)`、`F_R,rev(b)` 为给定电压、来流和命令下，左桨正推与右桨反推的实际推力**大小**。对理想平行、对称力臂为 d 的安装：

```text
X_prop = F_L,fwd(a) − F_R,rev(b)
N_prop = d · (F_L,fwd(a) + F_R,rev(b))
零纵向合力条件：F_L,fwd(a) = F_R,rev(b)
```

反向转弯需使用相反方向的两条实测曲线。不能只量一个满推比例，再假定它适用于所有命令和来流。

仅作线性算例：若 `F_fwd = k·a`、`F_rev = k_r·k·b`，则 `a = k_r·b`。取其他型号的示例 `k_r = 0.78`，在保持 b 不变并降低 a 的情况下，补偿后的偏航力矩约为原等值反号命令的 88%。这只是给定假设下的算术，不是本机配比。

消除桨的纵向合力不等于消除整机侧移；尾部 / 鱼体侧向作用、流场和瞬态仍需记录。因此不在此承诺无平移的原地转。

#### 6.3.4 横滚与向心力

绕鱼体纵轴横滚不会把沿该轴的推力转成横向分量：`R_x(φ)·[T, 0, 0]ᵀ = [T, 0, 0]ᵀ`。[48] 因此不能用纵向推力计算 `T·sinφ`，也不能据此求出所需滚角。

在静水、近似平面且速度稳定的圆弧运动中，世界坐标下的轨迹法向合力需满足：

```text
F_normal = m·U²/R_c = m·U·ω_χ
```

该力应由真实鳍面、鱼体和推进作用在轨迹法向上的分量求和。横滚可能改变鳍面 / 鱼体水动力的方向和大小，但实际效果取决于载荷及耦合，不能从滚角本身推出。比如 m = 2 kg、U = 1 m/s、ω_χ = 1 rad/s 只给出所需法向合力 2 N，不能确定滚角。

维持滚角另需核算横滚力矩与复原 / 阻尼作用，模型见研究报告。取得横滚与侧向载荷、姿态和航向响应的关系后，才比较横滚输入是否有益，不把它设为所有转弯必需的持续状态。

#### 6.3.5 周期载荷与纹波

尾部周期运动及其时间不对称可能在偏航和速度中引入周期波动，频谱可包含摆频及其谐波。波形是否表现为集中冲量、主要频率和机体响应幅值均需测量，不能统一规定为“每周期一次冲量”。

先记录尾相位、实际关节轨迹、偏航和视觉采样的时间关系，再决定是否需要相位相关处理。没有频率响应与控制权限证据时，不预设胸鳍能在摆频上反向阻尼，或双桨一定能消除某段波动。

#### 6.3.6 耦合的记录项

| 输入变化 | 可能影响 | 记录重点 |
|---|---|---|
| 双桨差动 | 偏航、纵向合力、反扭矩诱导横滚 | 左右正反推力及姿态，不能只看命令对称性 |
| 尾部时间不对称 | 周期波动、平均推进与偏航 | 行程不一定改变，但速度 / 载荷时序改变，净作用方向待测 |
| 胸鳍差动 / 偏转 | 横滚、侧滑、来流与阻力 | 迎角与载荷可能改变；完全浸没的刚性鳍偏转不等于湿面积增大 |
| 尾部偏置改变或回中 | 偏航控制作用及动态响应 | 与鳍面收起分开；稳定性变化需识别，不能预先指定 |

### 6.4 升沉：来流、姿态与推进共同建立

若合推进力近似沿机体纵轴，低头 θ_d 时它有向下分量 `T_axial·sinθ_d`；还须同时计入鳍面、鱼体载荷与净浮力。完整竖向预算见[研究报告](../pectoral_fin_depth_control_report.md) §4.2，不能只保留推力投影。

这一投影关系不推出输入必须串行。动作候选取决于胸鳍是否已有可用来流、推力线是否提供俯仰力矩及机构响应：

| 工况 | 可比较的候选 | 需确认什么 |
|---|---|---|
| 已有稳定来流，胸鳍有姿态权限 | 维持或调节推进的同时逐步改变胸鳍输入 | 可达姿态与下潜力预算是否同时成立 |
| 静止且胸鳍缺少来流 | 若推进确能建立鳍面来流，先逐步造流或与胸鳍输入共同建立 | 桨流是否覆盖鳍面，或航行速度何时足够 |
| 推力线偏离重心 | 联合调整推进和胸鳍，识别推力引入的俯仰作用 | 力矩方向、大小及复原作用 |
| 没有已知来流或可用俯仰通道 | 现构型未证明可从该状态建立所需姿态 | 不能以等待姿态建立替代缺失的作用来源 |

“先姿态、后推力”只在有其他作用维持姿态权限时才是可比较的方案，不是统一顺序。退出与故障动作继续服从现有安全设计，不由本节另行定义。

### 6.5 模式语义

现有 Bionic / Prop / Hybrid 保留为既有模式定义。按速度调度尾 / 桨参与程度是另一项候选设计，不要求把三种模式改成一条权重曲线，也不预设低速 / 高速的分界。

后续若采用连续调度，须先测量完整的混合输入工况，核实模式能力、过渡、反向与控制权接口。本文不把文献比较当作更改当前模式行为的依据。

### 6.6 本机待验证项

| 项目 | 需要取得的证据 | 不预设的结果 |
|---|---|---|
| 推进分配是否存在切换区 | 同机、同载荷、同速度下纯尾 / 纯桨 / 混合输入的功耗、轨迹与姿态 | 不保证存在交点，也不只比较两个单独模式 |
| 何时主动摆尾不利 | 实际 A_pp、频率、来流与主动 / 静态尾部对比 | 不采用统一的 0.3 或 0.48 停摆阈值 |
| 时间不对称的转向效果 | 半周期时间比、实际轨迹、平均作用与频谱 | 不预设 St 降低或只有一次冲量 |
| 近似零纵向力差动 | 左右桨、正反向、不同电压与来流下的推力曲线 | 不使用一个固定反推比例覆盖全域 |
| 输入建立与退出次序 | 同时 / 分时输入的延迟、峰值载荷与轨迹对比 | 不预设必须先桨后尾或必须逆序退出 |
| 横滚对转向是否有益 | 固定工况下的横滚、法向载荷、侧滑与航向响应 | 不由轴向推力直接计算滚角 |
| 升沉从哪些状态可启动 | 鳍面来流、推力线、姿态响应与净浮力 | 不预设可以停推进先建立姿态 |

## 7. 控制分层：L0 至 L3

以下职责已落实到 `control/l0`、`control/l1`、`control/l2` 和既有 Device／BSP。控制权与安全编排仍由既有 MotionController 持有，没有新增任务或优化求解器。

| 层 | 输入 → 输出 | 负责 | 不直接负责 |
|---|---|---|---|
| L0 策略 | 操作员 / 视觉 / 自动化请求与可用观测 → 模式与机体意图 | 来源适配、控制权、模式选择、已有或后续闭环 | 舵机角和 PWM 写入 |
| L1 指令 | 机体意图与权限快照 → 有效的归一化机体指令 | 范围、有效性、正常停止语义 | 选择步态、选择电气标定 |
| L2 分配 | 机体指令、模式、时间、几何与提交状态 → 六路目标 | 运动方案参数、相位、分配、几何与轨迹约束 | 定时器、电压补偿、PWM 写入 |
| L3 执行 | 六路目标与电气条件 → 提交结果 | 安装映射、电气标定、电压补偿、驱动写入及故障阻断 | 控制权、机体动作、步态选择 |

模式由 L0 选择，编排代码将其作为本周期上下文传给 L2；L1 的机体指令字段不需要包含模式或器件名称。跨模块业务沿用消息 / 快照，任务内部的纯计算可直接调用。

### 7.1 机体指令的语义

`l1::BodyCommand` 字段为 `surgePercent`、`yawPercent`、`pitchPercent`、`rollPercent`，范围 −100～100，加 `enabled`。它们是归一化请求，不是已闭环实现的 m/s、deg/s 或姿态角。

- `surge`：纵向推进请求，向前为正，经开环映射执行。
- `yaw`：左右转向请求，右转为正。
- `pitch`：抬头 / 低头请求；不得称为独立竖向速度控制。
- `roll`：右侧下沉为正；接口已接入，实际胸鳍 roll 增益未标定，默认 0。

L0 的 `BodyMotionTarget` 保留旧 LoRa 字段 `heavePercent`，适配为 pitch 请求，不宣称独立升沉。新算法可用 `submitBodyCommand(mode, command, generation)` 直接接入四轴；它不能自行授权启动，且与其他来源共用同一个 L2 根入口。

### 7.2 参数调度与相位

步态参数调度回答“本周期采用哪些幅值、频率、相位差与推进命令”；相位积分器负责根据频率和时间推进相位。两者职责不同。

```text
φ(k+1) = wrap(φ(k) + 2π · f(k) · Δt)
θ1 = β1 + A1 · sin φ
θ2 = β2 + A2 · sin(φ − δ)
```

`β` 是关节偏置，`A` 是关节角半幅，`δ` 是关节相位差。尾尖峰峰位移 `A_pp` 需由机构几何与实际轨迹求得，不能由一个关节角直接替代。

`control/l2/Allocator.cpp::allocate()` 每周期调用既有 `advanceGait()` 一次，再把同一个相位传给尾部子节点。旧 `updateCoordinatedMotion()`／`allocateBodyMotion()` 双路径已删除。PC DLL 用同一根分配器计算无状态目标预览，不能当作真实任务的限速／提交仿真。

幅值、频率和相位调度需要实测。本文不确定 1.3 Hz 下限、15° 标称幅值、90° 最优相位或固定分段点。

## 8. 分配、约束与提交结果

### 8.1 分配表达

可用“静态分量 + 周期分量 + 中立偏置”描述关节目标；只有参数、工况和饱和条件固定时，才能用固定矩阵表示。

双桨共同 / 差动命令可写为 `q_L = c + d_q`、`q_R = c − d_q`。胸鳍在统一物理角定义下可写为 `α_L = α_c + α_d`、`α_R = α_c − α_d`。这两组是命令混合，不是已经标定的牛顿 / 牛米分配矩阵。

同样的命令组合遇到不同流速、鳍姿态、推进器曲线，会产生不同的整机作用。L2 决定各关节的参与度与权重；第 5 节描述选定方案后关节实际怎样运动。安装极性由执行边界统一映射；迁移前须记录现有代码各处符号，不能直接再翻一次。

### 8.2 约束的归属

| 约束 | 处理位置 | 要求 |
|---|---|---|
| 机械行程 | L2 分配，L3 驱动保留边界 | 按各关节 / 各侧独立上下限计算，不能假定左右余量对称 |
| 偏置与摆幅共享行程（原 T8） | L2 | `A_i ≤ min(θmax_i − β_i, β_i − θmin_i)`，先验证偏置本身可行 |
| 胸鳍共同 / 差动共享行程（原 F4） | L2 | 同时约束两侧；缩放或优先级是待确认的分配策略 |
| 关节轨迹速度 | L2 | 恒幅正弦需求为 `2πfA`；变化的偏置、幅值及半划速度也占带宽 |
| 双桨命令范围 | L2 | 保留共同推进或让出共同推进以保转向，是两种不同策略 |
| PWM 范围、电压补偿 | L3 | 补偿后可以合法饱和，必须可诊断，不能要求所有限幅标志恒为 false |
| 独立电气速率兜底 | 后续候选 | 当前未实现；阈值、与停止路径的关系需另行设计 |

当前双桨策略优先保留共同命令，差动只使用剩余余量。因此共同命令达到满量程时差动归零；即使随后档位将两路整体缩小，也不会自动重新分配差动。这是现有算法行为，不代表硬件没有转向余量。

电压补偿的例子：参考 7400 mV、实测 6600 mV、名义命令 100%，补偿需求约 112%，执行层限制为 100%。这种饱和不自动证明 L2 错误。

### 8.3 写入成功不等于机构到位

现有六路提交不是原子事务，`writtenMask` 只说明各路驱动 API 是否接受了写入，不是舵机位置、转速或推力反馈。

应始终分清：本周期请求目标、上次成功提交的名义目标、电压补偿后的电气命令、实际测量值。最后一项当前缺少相应执行器传感器。

当前任务仅通过 `mergeWrittenFrame(committed_, output, writtenMask)` 更新成功名义历史，旧 SDK 虚拟油门／舵角状态已移除。电气值另存诊断，不回灌 L2；相位按时间推进，不因单路写失败回滚。

### 8.4 安全与诊断

安全策略输出本周期权限及原因，运动计算使用快照，执行端保留现有故障阻断。正常停止、链路租约退出、电池停机的目标姿态不同，不能统一成“六路全部回中”。具体状态、期限和恢复行为不在本文重新定义。

当前诊断已有尝试帧、成功提交帧、逐通道掩码、相位、共同 / 差动桨命令、三类分配限制、电池与安全状态。后续只补确实缺少的指令与步态参数，避免重建一套平行遥测。

## 10. 迁移与验证顺序

1. **建立行为基线**：在改代码前记录代表性命令序列的逐周期输入、相位、六路目标、补偿结果和提交掩码，覆盖模式、旋钮、转向、俯仰、停止及失败路径。
2. **整理职责**：复用已有相位积分、分配和诊断；先移动职责，保持输出、时序及取整行为。
3. **整理标定**：硬件几何、安装映射、电气参数各有唯一依据；命令来源的差异留在适配与请求语义中。合并双标定导致的输出变化单独说明。
4. **逐项改变行为**：调速、差动优先级、反向策略、roll 等分别设计与验证，不混入“仅重构”的验收。
5. **再接新控制入口或闭环**：先核实来源租约、过期目标和反馈坐标，再验证闭环。

| 验证对象 | 检查内容 | 能证明什么 |
|---|---|---|
| 纯计算 / 主机回归 | 有限值、范围、组合限位、相位连续、时间回绕、部分写入、补偿不累计、黄金向量 | 代码与接口约束 |
| 台架 | PWM 波形、真实中立、运动方向、带载轨迹、供电与电流 | 电气输出与机构跟随 |
| 单机构水池试验 | 推进、转向、鳍面响应；明确其余机构是否关闭或只提供来流 | 单机构在指定工况下的作用 |
| 整机试验 | 前后退、转弯、俯仰 / 横滚、下潜 / 上浮、退出行为 | 给定构型和负载下的整机能力 |

单机构研究指一次只识别一个机构的作用，不要求把提供必要来流的其他机构一律关闭。协同分配在这些作用明确后再展开。
