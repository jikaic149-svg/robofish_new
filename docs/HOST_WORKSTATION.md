# 机器鱼工作站交付

入口为桌面“机器鱼工作站”与 http://127.0.0.1:8765/ ，服务修订workstation-4。

操控/视觉/数据/开发四个主区，设备设置和统一日志抽屉。操控页同屏视频与三轴组合；模式选择单独提交，来源选择不夺取控制权。测试设置和底层维护折叠，删除装饰鱼和重复导航卡。

EmberProbe常规功能集中到网页，原版变量、波形、外设、RTOS和配置控件通过后台宿主复用；源码、断点、调用栈、内存与控制台直接在网页操作。实验性功能按约定暂缓。[逐项核对表](EMBERPROBE_PARITY.md)、[工作站README](../esp32s3/AmphiLink_UI/README.md)、[界面预览](workstation-preview.png)。

视觉页提供板载单窗口、视觉控制单窗口和双窗口；相机、模型与标定配置直接进入，原视觉按钮和网页按钮均已放大。顶部明确说明遥测记录内容；开发页常显探针、芯片与链路状态。[视觉布局预览](vision-layout-preview.png)。

本轮验证：79项PC测试、原生任务与网页传输、真实控件消息、三种视觉布局、实际遥测导出和390px布局。真实录像加载所选模型并处理画面切换；原工具栏点击区域一致。布局测试使用拦截画面，板载相机实机仍待验收；未连接或操作芯片。

实物LoRa发送/遥测上行仍未接入，HTTP/SPI管理链不代发运动。此次未修改两端固件，维护工具不等于完整受保护无线OTA已经验收。
